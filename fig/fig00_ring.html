平面の点を、整数4つ (a0, a1, a2, a3) ＝ a0 + a1ζ + a2ζ² + a3ζ³ で書きます。ζ は 36° 回った一歩で、ζ を一回掛けるのは (c0, c1, c2, c3) → (−c3, c0+c3, c1−c3, c2+c3) という足し算と引き算だけです。φ ＝ (1, 0, 1, −1)、φ² ＝ φ + 1 ＝ (2, 0, 1, −1) です。

最初の場面では、中心のまわり φ²·ζ^k（k ＝ 0〜9）に五角形を一枚ずつ置きます。k が番地で、番地の偶奇で五角形の向きが決まり、5で割った余りで色が決まります。隣どうしは辺で接し、10枚で輪が閉じます。

次の場面では、同じ円環を中心から φ³ の距離に5個置きます。席は 50 ありますが、二つの円環が同じ五角形を分け合うので、五角形は 40 枚です（太い枠が分け合う五角形）。真ん中には五角形の置かれない穴が残り、その形は五芒星です。

図の中の計算は整数の足し算と引き算だけです。画面の座標に直す最後の一回だけ、観察者側の表示として実数を使っています。
