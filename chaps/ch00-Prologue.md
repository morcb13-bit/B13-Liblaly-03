## 序章　五角形10枚の円環から始めるペンローズターリングの世界
---

前の本は「二つの1から形まで」で終わりました。1 と 1 を足して 2、1 と 2 を足して 3、と足し算だけで続けていくと、隣どうしの比は φ に近づいていきます。φ は足し算から生まれる数で、

$$
\varphi^2 = \varphi + 1
$$

という関係を持ちます。表紙に置いたのもこの一行です。

この本では、整数を一本の数直線から平面へ広げます。平面に整数を並べると、同じ五角形が規則正しく並んでいるのに、どこまで行っても同じ並びが繰り返されない模様が現れます。この模様が何と呼ばれているかは、第6章で明かします。それまでは、整数と足し算だけで模様を組み上げていきます。

## 平面の点を整数4つで書く

数直線の上では、一歩は「1 を足す」ことでした。平面では、もう一つの一歩を用意します。36° 回った方向へ進む一歩で、これを ζ と書きます。

ζ を5回続けると半周回って、ちょうど逆向きの一歩になります。10回続けると一周して元に戻ります。

$$
\zeta^5 = -1, \qquad \zeta^{10} = 1
$$

さらに、ζ を4回続けた一歩は、1・ζ・ζ²・ζ³ の足し引きで書けます。

$$
\zeta^4 = -1 + \zeta - \zeta^2 + \zeta^3
$$

このため、平面のどの点も整数4つで書けます。

$$
(a_0, a_1, a_2, a_3) = a_0 + a_1\zeta + a_2\zeta^2 + a_3\zeta^3
$$

点を 36° 回すには、ζ を一回掛けます。整数4つで書くと、これは足し算と引き算だけの並べ替えです。

$$
(c_0, c_1, c_2, c_3) \;\to\; (-c_3,\; c_0 + c_3,\; c_1 - c_3,\; c_2 + c_3)
$$

φ もこの4つの整数で書けます。

$$
\varphi = 1 + \zeta^2 - \zeta^3 = (1, 0, 1, -1), \qquad \varphi^2 = \varphi + 1 = (2, 0, 1, -1)
$$

:::message
**観察者側の整理（既存の数学の言葉）**
ζ は複素数 $e^{i\pi/5} = \cos 36^\circ + i\sin 36^\circ$ にあたり、整数4つで書ける点の集まりは 10 次の円分整数環 $\mathbb{Z}[\zeta_{10}]$ と呼ばれています。φ ＝ (1 + √5) / 2 です。この本の計算では、これらの実数の値は使いません。画面に描くときに一回だけ実数に直します。
:::

## 五角形を一枚置く

五角形の中心を点 c に置き、5つの頂点を c から ζ^(a), ζ^(a+2), ζ^(a+4), ζ^(a+6), ζ^(a+8) の方向へ一歩ずつ進んだ所に打ちます。a をこの五角形の**番地**と呼びます。

番地を 2 増やしても同じ5頂点が並ぶので、五角形の向きは番地の偶奇だけで決まります。偶数の番地と奇数の番地では、五角形が 36° 回った向きになります。

## 五角形10枚の円環

中心のまわりの φ²·ζ^k（k ＝ 0, 1, …, 9）に、番地 k の五角形を置きます。これがこの本のいちばん小さな部品、**円環**です。

[計算] 隣どうしの五角形の中心の距離² は、どの組も 1 + φ ＝ φ² で、距離は φ です。五角形の頂点が中心から距離 1 にあるとき、辺で接する二枚の中心はちょうど φ だけ離れるので、10枚は隙間なく辺で接し、輪が閉じます。

## 円環を5個置くと、真ん中に五芒星が残る

円環を一つの点のまわりに5個置きます。円環の中心は、真ん中から φ³ の距離に 72° おきに並べます。最初の円環の中心は (3, 0, 2, −2) で、ほかの4つはこれを ζ² ずつ回したものです。

[計算]
- 5つの円環の中心の距離² はどれも 5 + 8φ ＝ φ⁶ で、距離は φ³ です。5つの中心を足すと (0, 0, 0, 0) に戻ります。
- 席は 5 × 10 ＝ 50 ですが、隣り合う二つの円環が五角形を1枚ずつ分け合うので、五角形は 40 枚になります。分け合う 10 枚では、どちらの円環から見ても番地の偶奇が一致し、向きが食い違いません。
- 40 枚のどの二枚も、中心の距離が φ より近くならないので、重なりはありません。
- 真ん中には五角形が置かれず、距離 φ の5方向に五角形が並びます。そこに残る穴の形は五芒星です。

負の対照として、円環の中心を φ³ ではなく φ² の距離に置くと、五角形は 36 枚になり、真ん中の点そのものに五角形が来て、五芒星の穴は残りません。円環の置き方を一段変えると、真ん中に何が残るかが変わります。

## 2 と 3 に戻す

自然は 2 と 3 でできている、というのがこの本の立場です。序章で出てきたものを、2 と 3 に戻しておきます。

- φ は 1, 1, 2, 3, 5, … と足していく列から生まれました。足し算が最初に作る新しい数が 2 と 3 です。
- 五角形の 5 は 2 + 3、円環の 10 枚は 2 × 5 です。
- [計算] 円環の中心から五角形の中心までの距離² は 2 + 3φ ＝ φ⁴ でした。円環の大きさそのものが、2 と 3 の組で書かれています。

## 検算

ここまでの数は、次のスクリプトで出しました。整数の足し算と引き算だけで書いてあり、このファイルだけで走ります。

```
$ python3 ch00_ring.py
1. 一歩と回る一歩
   ζ⁵ = (-1, 0, 0, 0) （半周で −1）   ζ¹⁰ = (1, 0, 0, 0)
   φ  = (1, 0, 1, -1)   φ·φ = (2, 0, 1, -1)   φ + 1 = (2, 0, 1, -1)   一致: True
2. 円環1個
   五角形 10 枚。隣どうしの距離² = {(1, 1)} ＝ 1 + φ ＝ φ² → 距離 φ
   中心からの距離² = {(2, 3)} ＝ 2 + 3φ ＝ φ⁴ → 距離 φ²
3. 円環5個（真ん中を空けて囲む）
   円環の中心: [(3, 0, 2, -2), (0, 2, 1, 2), (-3, 1, -1, 3), (-2, -1, -2, 0), (2, -2, 0, -3)]
   中心からの距離² = {(5, 8)} ＝ 5 + 8φ ＝ φ⁶ → 距離 φ³
   G の距離² と φ³ の距離² が同じ: True
   中心の和 = (0, 0, 0, 0)
   席 50 → 五角形 40 枚。二つの円環が分け合う五角形 10 枚
   分け合う五角形で向き（番地の偶奇）が食い違うもの: 0
   φ より近い五角形の組: 0 （0 なら重ならない）
   真ん中に五芒星の穴が残る: True
4. 負の対照：円環を中心から φ² の距離に置いた場合
   中心からの距離² = (2, 3) ＝ 2 + 3φ ＝ φ⁴ → 距離 φ²
   五角形 36 枚。原点に五角形がある: True   真ん中に五芒星の穴が残る: False
```

距離² は (p, q) ＝ p + qφ の整数の組で表しています。距離を比べるときも √5 を数として持たず、整数の大小だけで判定しています。

## この本の道筋

- **第1部　平面を敷く**：円環をつなぎ、番地をふり、五芒星から景色を見ます。第6章で模様の名前を明かします。
- **第2部　平面で計算する**：敷いた平面を計算尺や記憶の網として使います。
- **第3部　平面で見る**：平面を網膜にして、形を見分けます。
- **第4部　平面で動かす**：平面の上で波や流れを走らせます。
- **終章**：平面の影を立体に持ち上げ、次の本へつなぎます。

1 と 1 から φ が生まれ、φ から円環が生まれ、円環5個が五芒星を囲みました。この本は、この 40 枚の五角形と真ん中の五芒星から始めて、平面をどこまでも整数だけで敷き、そのたびに 2 と 3 に戻していきます。
