---
第14章　ずらすと窓になる ── 中心の五角形をずらす（第四のつまみ）
---

第12章で、網膜を動かす三つのつまみを使いました。**中心・向き・大きさ**です。この章では、四つ目のつまみを足します。**平面をずらした写しと重ねる**ことです。

平面（五角形 6030 枚）を番地 d だけずらした写しを、元の平面に重ねます。ずらしても五角形が五角形にぴったり重なる場所を、ずらしが開いた**窓**と呼びます。重なる枚数を m(d) と書きます。ずらしは、4 つの成分がどれも −4〜4 の番地 6560 本を全部調べます。

## 二つの組

第6章で、番地 (a0, a1, a2, a3) の a0 − a1 + a2 − a3 を 5 で割った余りを見ました。これを番地の組と呼びます。

[計算]（検定1）
- 五角形の番地の組は **2 と 4 の 2 種類だけ**で、どちらも 3015 枚ずつです。
- ずらしの組が 1 か 4 のときは、1312 本のどれも重なりが 0 です。組 2 の五角形を組 3 や組 1 へ運んでも、そこに五角形はありません。
- ずらしの組が 0（同じ組の中で動かす）か 2・3（二つの組を入れ替える）のときだけ、重なることがあります。

平面の五角形は、二つの組に分かれて並んでいます。ずらしで窓が開くかどうかは、まず組が合うかどうかで決まります。

## 窓の開き方は残渣で決まる

組を変えないずらし（組 0）だけを取り出します。ずらしの番地の ζ を ζ³ に読み替えたもの（第4章の残渣）の長さ² を (p ＋ q) − qφ で計算し、重なりの枚数と並べます。

[計算]（検定2）

| 残渣² | 重なり |
|---|---|
| 47 − 29φ（0.077） | 4317 |
| 18 − 11φ（0.202） | 3684 |
| 65 − 40φ（0.279） | 3088 |
| 7 − 4φ（0.528） | 2424 |
| 25 − 15φ（0.729） | 1848 |
| … | … |
| 10 − 5φ（1.910） | 168 |
| 57 − 34φ（1.987） | 166 |
| 28 − 16φ（2.111） | 144 |
| 17 − 9φ（2.438） | **0** |

- 重なりの枚数は**残渣の長さだけで決まり**ます。残渣が同じなら、ずらしの向きや実際の長さが違っても、枚数は同じです。
- 残渣が長くなるほど重なりは減り、残渣² が 28 − 16φ と 17 − 9φ の間を越えると 0 になります。**窓が閉じます。**

ずらしは、窓の開き具合を決めるつまみです。カメラの絞りのように、残渣を長くするほど窓が狭まり、ある所で閉じます。

## 短いずらしほど閉じる

ずらしの実際の長さ² と残渣の長さ² を掛けると、整数（ノルム N）になります。

[計算]（検定3）
- 6560 本のすべてで、長さ² × 残渣² は 1 以上の整数です。
- 組を変えないずらしで実際の長さが最も短いもの（長さ² 47 − 29φ ≈ 0.077）は、残渣² が 18 ＋ 29φ と長く、**重なりは 0** です。
- 重なりが最も大きいずらし（4317 枚、72%）は、長さ² 18 ＋ 29φ（≈ 64.9）で、残渣² は 47 − 29φ です。

最も短いずらしと、最も大きく開くずらしは、実際の長さと残渣の長さが**ちょうど入れ替わった**組になっています。実際に近いずらしほど残渣では遠く、窓は閉じます。実際に遠いずらしほど残渣では近く、窓は大きく開きます。実空間の直感とは逆です。

**観察者側の整理（既存の数学の言葉）**
ペンローズタイリングを高い次元の格子の切断と射影（cut-and-project）で作ると、点が選ばれるかどうかは、射影したもう一方の空間（内部空間）で「窓」に入るかどうかで決まります。ここでの残渣はその内部空間の座標にあたり、ずらした写しとの重なりは、窓とずらした窓の共通部分の大きさにあたります。実際の長さ × 残渣の長さが整数になるのは、Z[φ] の元のノルムが整数になることの言い換えです。この本では窓の形を外から与えず、平面の五角形をずらして重ねて数えるだけで、窓の開き閉じを読んでいます。
:::

## 2 と 3 に戻す

- 五角形の番地の組は 2 種類で、窓が開くかどうかはまず組が合うかで決まります。
- ずらしで重なる組の動きは、組の中（0）と、組の入れ替え（2 と 3）の 2 通りです。
- 実際の長さと残渣の長さは、掛けると整数になる 2 つの物差しで、一方が縮めば他方が伸びます。

平面をずらした写しと重ねると、五角形は二つの組に分かれていて、組の合わないずらしは決して重なりませんでした。組の合うずらしでは、重なりの枚数が残渣の長さだけで決まり、残渣が長いほど狭まって、28 − 16φ と 17 − 9φ の間で閉じました。実際に最も短いずらしは閉じ、実際に遠いずらしが最も大きく開きました。この章の結論は、**平面をずらして重ねると、残渣の長さで開き閉じする窓になり、ずらしは網膜の四つ目のつまみ（絞り）として働く**ということです。
